# Tapwise: NFC Idea Finder

A small website that asks about your everyday life and suggests NFC tag ideas that fit it, explains why each one is worth trying, credits the creators who show how, and tells you which tag to buy.

Built by the user together with Claude (Anthropic) and NotebookLM (Google). Work in progress.
